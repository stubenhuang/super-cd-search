## Codebase Patterns
- Use `electron-vite` for building Electron app with React
- CSS imports need `env.d.ts` with module declaration for TypeScript
- Use `ELECTRON_MIRROR` env var if npm install fails on electron binary download
- TypeScript project references require `composite: true` in referenced configs
- Database files should be stored in `app.getPath('userData')` for cross-platform compatibility
- Use electron-store with encryptionKey for secure settings storage
- Renderer type declarations must be self-contained (cannot import from main process)
- Use `browserPool.acquire()` / `browserPool.release()` for all Puppeteer operations
- Use `throttledFetch(domain, url, options)` for all HTTP requests to avoid rate limits
