# Super CD Search — 产品想法池（CD 卖家视角）

> 定位：不是淘碟工具，而是 **CD 卖家工作台**。
> 核心目标：用尽量少的操作，搞清楚一张碟该卖多少钱、能赚多少钱，以及如何更快地整理库存、定价和上架。

| 功能 | 分类 | 优先级 | 一句话说明 |
|------|------|--------|------------|

| 平台费用与利润计算器 | 卖家刚需 | P0 | 估算 eBay / Discogs / PayPal 等费用，展示售价到净利润 |

| 竞品价格监控 | 效率工具 | P1 | 定时复查重点碟价格，价格变化时提醒 |
| 批量定价 / 批量改价 | 效率工具 | P1 | 表格视图批量设置售价、品相、库存，按规则生成价格 |

## 一、卖家刚需（最值得先做）

### 1. 库存管理（店铺后台）

把搜索过的目录号保存为库存条目，字段建议：

- 目录号、标题、艺术家、版本
- 进货成本（含运费、代购费、其他成本）
- 品相（Discogs 评级：M / NM / VG+ / VG / G+）
- 数量、入库日期、存放位置
- 目标售价、最低可接受价
- 销售状态：在售 / 已售 / 下架 / 待上架
- 备注

额外能力：

- 支持 CSV / Excel 批量导入历史库存
- 库存列表支持筛选、排序、批量操作
- 数据建议用 SQLite 持久化

### 2. 定价建议

利用现有多平台比价能力，反过来为卖家服务：

- 自动计算：最低成交参考价、中位数、近期成交价
- 数据源建议：Discogs `marketplace/stats`、eBay sold listings
- 输出三档建议：
  - 建议售价
  - 快速出单价
  - 挂高价慢出价
- 结合进货成本显示预估利润和利润率
- 支持定价策略：
  - 比全网最低价低 5%
  - 按中位数 +10%
  - 按成本 +固定比例

### 3. 平台费用与利润计算器

卖家每天都要算、又最容易算错的部分：

- 分别估算各平台到手金额：
  - eBay 成交费 + 支付处理费
  - Discogs 8% 卖家费
  - 平台广告 / 推广费
  - PayPal 手续费
  - 国内 / 国际运费
- 输出链路：
  - 售价 → 平台费 → 运费 → 净到手
  - 净到手 − 进货成本 → 净利润
- 可针对不同币种和不同买家地区估算

### 4. 多版本识别

同一个目录号经常对应多个版本，价格差异可能很大：

- 展示该目录号的所有 Discogs 版本：
  - 初版 / 再版
  - 带侧标 / 无侧标
  - 见本盘 / 通常盘
  - 不同地区、不同年份
- 详情页可切换查看不同版本的年份、格式、国家、厂牌、封面
- 帮助卖家快速确认自己手里的货是哪一版，避免把高价版本按普通版卖掉

## 二、效率工具

### 5. 多平台上架文案生成

不直接做自动发布，先生成高质量上架草稿：

- Discogs 上架文案：
  - 标题、版本、品相、附件情况、说明模板
- eBay 标题模板：
  - 自动拼接关键词，例如：
    `Pink Floyd Animals 2018 Remix CD Japan OBI SICP-6480 NM`
- Yahoo Auction 日文文案草稿
- 自动填入：格式、厂牌、国家、发行日期、目录号、条形码
- 支持复制即用

### 6. 竞品价格监控

- 对库存中的重点碟定时复查
- 监控指标：
  - 当前全网最低价
  - 在售卖家数量
  - 自己的价格排名
- 价格变化提醒：
  - `SICP-6480 最低价从 $31 降到 $24`
- 支持按平台和目录号订阅

### 7. 批量定价 / 批量改价

- 表格视图批量编辑：
  - 售价
  - 最低价
  - 品相
  - 库存数量
- 规则化批量生成价格：
  - 所有 CD 按成本 +20%
  - 所有 NM 品相加 $5
  - 90 天未售出的自动降 10%

### 8. 品相辅助判断与标记

- 详情页快速标记品相：M / NM / VG+ / VG / G+
- 每个品相对应备注模板，如：
  - `OBI 有轻微折痕`
  - `盘面有细划痕，不影响播放`
- 导出 Excel 时带品相列
- 后续可加入 Discogs 品相标准说明

### 9. 条形码 / JAN 码入库

- 支持摄像头扫描或手动输入 JAN / EAN
- 自动匹配 Discogs 版本
- 扫描 → 自动建档 → 生成定价建议，加快入库速度

### 10. 发货单 / 拣货单 / 报关单

- 从库存勾选一批碟，生成：
  - 拣货清单
  - 地址单
  - 装箱单
- 海外卖家可生成 CN22 报关单草稿

## 三、经营分析

### 11. 销售记录与毛利统计

- 记录每张碟：
  - 实际售价、平台、买家地区
  - 运费、手续费
  - 采购成本、其他成本
- 仪表盘：
  - 本月销售额、净利润、利润率
  - 最好卖的厂牌 / 艺术家 / 类型
  - 平均周转天数
- 数据积累后用于指导进货

## 四、酷炫功能（可后置）

### 12. 拍照 / OCR 自动建档

- 拍一张 CD 封面或侧标照片
- 自动识别：
  - 目录号
  - JAN 码
  - 标题 / 艺术家
  - 品相
- 识别后自动搜索多平台，生成定价建议
- 技术路线：本地 OCR 或视觉 LLM

### 13. AI 商品描述生成

- 基于专辑信息自动生成上架文案
- 支持中 / 英 / 日三语
- 模板化输出：
  - Discogs 简洁版
  - eBay SEO 标题 + 详情版
  - Yahoo Auction 日文版
- 与现有 LLM 能力复用

### 14. 库存封面墙

- 库存以封面墙形式展示
- 用颜色 / 角标表示状态：
  - 绿色：利润好、可出
  - 黄色：挂售较久、建议降价
  - 红色：低于成本线
- 视觉上像唱片架，符合当前复古设计风格

## 五、推荐实施路线

1. **第一阶段：卖家工作台基础**
   - 库存管理
   - 定价建议
   - 平台费用与利润计算器

2. **第二阶段：效率提升**
   - 多平台上架文案生成
   - 批量定价 / 批量改价
   - 多版本识别
   - 销售记录与毛利统计

3. **第三阶段：自动化与 AI**
   - 竞品价格监控
   - 拍照 / OCR 自动建档
   - AI 商品描述生成

4. **第四阶段：视觉与运营辅助**
   - 库存封面墙
   - 发货单 / 拣货单 / 报关单
   - 条形码 / JAN 码入库

> 建议后续先从**数据结构设计**开始：库存表、价格记录表、销售记录表。所有卖家功能都可以在这套结构上生长。
